# 3afret Platform | المنصة الرسمية لعلامة 3afret

منصة إلكترونية احترافيّة متكاملة لعلامة **3afret**، مخصصة لخدمات بيع وشراء الحسابات، فروع وجروبات التداول، متجر الشحن المباشر عبر واتساب، خدمات ضمان فيسبوك، ومعارض إعلانات المشاهير وصناع المحتوى، مع لوحة تحكم إدارية كاملة ومحمية.

---

## 🌟 المميزات الرئيسية

1. **الهوية البصرية الفاخرة**:
   - تصميم أسود ملكي (Obsidian Dark) مطعم بلمسات ذهبية عاكسة (Luxury Gold) وتأثيرات زجاجية (Glassmorphism).
   - خطوط عربية حديثة ودعم كامل لاتجاه الكتابة من اليمين إلى اليسار (RTL).
   - شعار رسمي لعلامة 3afret وأيقونات المنصات المعتمدة (واتساب، تليجرام، فيسبوك، ديسكورد، تيك توك).

2. **فروع وجروبات البيع والشراء**:
   - إمكانية إضافة عدد غير محدود من الفروع والجروبات.
   - تصنيف الجروبات حسب نوع الخدمة (VIP، نادرة، وساطة، عام).
   - شريط بحث فوري لتسهيل عثور الزوار على الجروب المناسب.
   - كروت تفاعلية مزودة بأزرار الدخول المباشر وزر نسخ الرابط.

3. **القناة الرسمية للبيع والشراء**:
   - قسم VIP مخصص مع بانر رسمي، مميزات التوثيق، وزر انضمام فوري.

4. **متجر الشحن المباشر عبر واتساب**:
   - زر تواصل فوري يفتح محادثة واتساب مع رسالة افتتاحية مخصصة.
   - قابل للتعديل بالكامل من لوحة التحكم.

5. **قسم ضمان فيسبوك**:
   - عرض منشور الضمان والوساطة المعتمد مع شرح شامل لإجراءات الأمان وحماية الأموال.

6. **قناة تيك توك الرسمية**:
   - كارت تفاعلي يعرض الحساب، اسم المستخدم، البايو، إحصائيات المتابعين، وزر المتابعة.

7. **معرض نجوم ومشاهير 3afret**:
   - عرض فيديوهات المشاهير في شكل شبكة بطاقات مع مشغل فيديو مدمج (Video Modal).
   - دعم رفع ملفات MP4 المباشرة، روابط يوتيوب، وروابط تيك توك.

8. **إحصائيات المنصة الحية**:
   - عدادات ديناميكية قابلة للتعديل من لوحة التحكم (أعضاء، فروع، جروبات، تقييم).

9. **لوحة تحكم الإدارة (Admin Dashboard)**:
   - رابط الوصول: `/admin` أو `/admin/login`.
   - كلمة المرور الافتراضية: `admin123`.
   - إدارة الفروع والجروبات (إضافة، تعديل، حذف، تغيير الروابط).
   - إدارة القنوات والضمان والمتجر وتيك توك.
   - إضافة وحذف وتعديل فيديوهات المشاهير مع إمكانية رفع الملفات والصور.
   - تعديل جميع نصوص وبانرات الموقع.
   - التحكم في ترتيب وظهور الأقسام.
   - تغيير كلمة مرور الإدارة بأمان.

## 🚀 تشغيل المشروع محلياً

```bash
# تثبيت الاعتماديات (تم بالفعل)
npm install

# تشغيل بيئة التطوير
npm run dev

# أو بناء وتشغيل النسخة النهائية للإنتاج
npm run build
npm run start
```

الموقع متاح على الرابط: `http://localhost:3000`  
لوحة التحكم متاحة على الرابط: `http://localhost:3000/admin`
